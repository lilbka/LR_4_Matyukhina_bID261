# Домашнее задание к лабораторной работе 4
## Условие задачи
Ученый проверяет гипотезу о трех числах. Гипотеза подтверждается, если каждое из трех экспериментально полученных чисел (A, B, C) кратно трем. Запишите условие подтверждения гипотезы.

## 1. Алгоритм и блок-схема
### Алгоритм
1. Начало
2. Объявить переменные:
A, B, C — три целых числа

3. Ввести исходные данные: 
Вывести сообщение "введите число a: " ; 
Cчитать a с клавиатуры ; 
Вывести сообщение "введите число b: " ; 
Считать b с клавиатуры.
Вывести сообщение "введите число c: " ; 
Считать c с клавиатуры.

4. Вычислить остатки от деления на 3:
ostA = A % 3 ;
ostB = B % 3 ;
ostC = C % 3 ;

5. Вычислить сумму остатков:
s = ostA + ostB + ostC

6. Вывести A, B, C, остатки и сумму остатков. Если сумма остатков равна нулю, то все три числа кратны 3.

7. Конец
